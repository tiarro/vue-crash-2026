## What I found
- This is a Vue 3 + Vite project.
- Scripts: `npm run dev`, `npm run build`, `npm run preview`.
- Dev server is configured to use port 3000.
- Node engine required: Node ^20.19.0 or >=22.12.0.

## Plan to run it (dev mode)
1. Check Node and npm versions meet the project requirement.
2. Install dependencies from the project root:
   - `npm install`
3. Start the dev server:
   - `npm run dev`
4. Open the app in the browser at:
   - `http://localhost:3000/`
